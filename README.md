# Personal WorkHub 個人工作資產與日曆式知識庫系統

> **專為 Windows 環境打造的極速、離線、免連網個人工作助理與技術資產庫**  
> 整合「日曆排程」、「Notion 頁面式排查紀錄」與「客戶技術知識庫」，所有資料 100% 儲存在本地端 Markdown 與 JSON 格式，隱私安全無虞。

---

## 🚀 一鍵啟動與關閉指南

### 1. 如何啟動系統？
* **雙擊根目錄的 `PersonalWorkHub.exe`**：
  * **完全零黑窗（No Console Window）**：背景靜默喚起 Node.js 服務，不會跳出任何干擾的命令提示字元黑視窗。
  * **自動喚起瀏覽器**：服務啟動後自動打開預設瀏覽器並導向 `http://localhost:3000/`。
  * **防重複拉起**：若服務已在運行，雙擊會直接開啟現有網頁，不會重複佔用 Port。

### 2. 如何關閉系統？
* **直接關閉瀏覽器視窗即可！**
  * 系統內建「**智慧心跳監控（Heartbeat Monitor）**」，前端頁面會定期向伺服器發送心跳信號。
  * 當您關閉所有 WorkHub 瀏覽器分頁時，後端服務在偵測到連線中斷（約 15 秒）後會**自動優雅退出，自動釋放 Port 3000 與記憶體**，無需手動執行任何關閉指令。

## 📂 專案目錄與架構說明

經過輕量化整理後，專案結構清晰簡潔，各模組職責劃分如下：

```text
todolist/
├── PersonalWorkHub.exe    # 【主要啟動器】Windows 原生無黑窗一鍵啟動程式
├── README.md              # 系統架構、目錄說明與使用文件
├── package.json           # Node.js 專案依賴與套件設定檔
├── package-lock.json      # 套件版本鎖定清單
├── .gitignore             # Git 版本控制忽略暫存檔設定
│
├── server/                # 【後端服務層】
│   └── index.js           # Express API 伺服器：負責待辦/日曆運算、筆記讀寫、圖片上傳與心跳監控
│
├── client/                # 【前端展示層】
│   ├── index.html         # 系統單頁主結構（日曆、側邊抽屜、Notion 頁面彈窗、知識庫編輯器）
│   ├── style.css          # 全域深色系高質感主題、Notion 表格佈局與流暢動畫樣式
│   ├── app.js             # 前端核心邏輯（所見即所得編輯、自動防抖存檔、快速新增、快捷鍵）
│   └── libs/              # 前端離線依賴函式庫（完全無需連外網）
│       ├── marked.umd.js  # Markdown 解析與渲染器
│       └── turndown.js    # HTML 所見即所得自動轉回 Markdown 儲存引擎
│
├── data/                  # 【個人資產資料庫】（⚠️ 最重要的實體資產，請妥善備份）
│   ├── todos/             # 待辦與工作日程資料庫（按月分檔儲存，如 2026-10.json）
│   ├── notebooks/         # 個人技術知識庫（依客戶/專案分類儲存的標準 Markdown 文件）
│   ├── templates/         # 內建工作模板庫（技術排錯、客戶訪談、SQL 效能調校等）
│   └── assets/            # 貼圖與媒體附件庫（在筆記/任務中 Ctrl+V 貼上的截圖皆集中儲存於此）
│
└── node_modules/          # 後端 Express 及相關依賴套件庫
```

## 🌟 核心功能特色

### 1. 外層分離：極簡「原地快速建立」（免開彈窗）
* 在日曆右側抽屜頂端提供 `[＋ 輸入任務名稱，按 Enter 快速建立...]` 輸入框。
* 日常瑣事直接輸入名稱按下 `Enter` 即可立即於當日建立任務，省去每次都要填寫複雜表單的繁瑣步驟。

### 2. 內層聚合：100% Notion 頁面格式任務彈窗
* 點擊任務卡片即展開比照 Notion 的全功能頁面，具有：
  * **無邊框 H1 大標題**：清晰直觀的主題定義。
  * **垂直鍵值屬性表（Properties Table）**：
    * ☑️ **Done**：核取方塊，勾選自動聯動標籤狀態。
    * 📅 **工作日期**：支援「起訖日區間」，可設定跨日長期任務並在月曆以連貫橫條（Multi-day Bar）呈現。
    * 🔆 **優先次序**：優先完成（High）/ 普通（Normal）/ 低優先（Low）。
    * 🏢 **客戶標籤**：北富銀、國瑞汽車、宏碁Acer 等客戶自動建議選單。
    * ⚡ **執行狀態**：進行中、移到下週一、等待客戶回覆、測試驗證中、已完成。
  * **執行步驟清單（Sub-tasks）**：支援按 `Enter` 快速換行增加步驟、按 `Tab` 縮排為子步驟。
  * **單一連續滾動（Continuous Page Scroll）**：徹底移除傳統巢狀彈窗的滾軸卡死問題，整頁採用單一原生滑鼠滾輪，長篇排錯紀錄與截圖一滑到底。
  * **全螢幕切換（⛶）**：支援視窗模式與全螢幕沉浸式放大。

### 3. 所見即所得（WYSIWYG）與自動 Markdown 雙向同步
* 筆記與任務內容支援直接排版（粗體、代碼區塊、田字表格插入、💡提示框、⚠️警告框、折疊區塊）。
* 支援 **Ctrl+V 截圖直接貼上**，圖片自動保存至 `data/assets/` 目錄並以本地路徑引用。
* 背景採用「**自動防抖存檔（Debounced Auto-save）**」，您打字的同時已自動轉為標準 Markdown 格式並儲存到硬碟，永不遺失進度。

### 4. 工作紀錄沉澱至知識庫（Promote to Notebook）
* 在任務彈窗點擊「⭐ 沉澱至知識庫」，系統會自動提取任務的執行步驟清單與排查筆記，自動歸類建立至 `data/notebooks/{客戶分類}/{任務名稱}.md`。
* 任務完成的同時，技術資產即自動完成歸檔與沉澱。

### 5. 全局全文秒級檢索（Ctrl+K）
* 隨時按下 `Ctrl + K` 快捷鍵，即可瞬間檢索跨月份的所有待辦任務、執行步驟清單以及知識庫 Markdown 筆記全文。

## 💾 資料備份建議

本系統遵循 **Local-First（本地優先）** 原則，所有產出皆為開放的標準檔案格式：
* 若需要備份資料或移轉到其他電腦，**只需複製 `data/` 資料夾** 即可！
* `data/todos/` 中的 JSON 檔可用任何文字編輯器讀取；`data/notebooks/` 中的 Markdown 檔亦可直接使用 VS Code、Obsidian 或 Typora 等工具開啟。
